# 🚀 ForgeProject

> **Open-Source Engineering Reference Repository & Technical Viva Defense Platform**
> 450 Verified Engineering Project Architectures across 9 Core Technical Domains with In-Browser Architecture Slide Presenters, Technical Specifications, and Interactive Viva Voce Defense Simulators.

---

## 🌟 Key Features

- **450 Verified Engineering Architectures**: Curated across 9 domains (AI & Machine Learning, IoT & Embedded Systems, Java Enterprise, Mobile Flutter, Blockchain Web3, Web & Full Stack, Python Data Science, Cybersecurity, and C/C++ Systems).
- **In-Browser Architecture Slide Viewer**: 10-slide architectural blueprints for each project with slide navigation, presenter notes, and fullscreen mode.
- **Interactive Viva-Voce Defense Simulator**: Practice examiner defense questions with live feedback, technical scoring, and architectural reasoning.
- **1-Click Architecture Study Kit**: Bundles complete verified source code, IEEE-formatted technical synopses, system specifications, and defense cheat sheets.
- **Architecture Presentation Studio**: Format title slides and documentation attribution for academic seminars and tech reviews.
- **Fast Progressive Directory**: Instant category, degree, and academic year exploration.
- **Educational Fair-Use & Honor Code**: Built strictly for reference implementation, self-study, and defense rehearsal. Direct uncredited submission of materials as coursework is prohibited.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & Neon Glow Tokens), JavaScript (ES6+)
- **Icons & Libraries**: Lucide Icons, JSZip, FileSaver.js, Canvas Confetti
- **Backend & Database**: Python 3 HTTP Server, MongoDB (Optional Cloud/Local Persistence)

---

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/adityanegi-hu/project.in.git
   cd project.in
   ```
2. Start the local development server:
   ```bash
   python server.py
   ```
3. Open `http://127.0.0.1:3000` in your browser.
