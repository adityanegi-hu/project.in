# 🚀 ProjectForge

> **Next-Gen Engineering Project Repository & Interactive Viva Defense Platform**
> 450 Verified, Working Academic Projects across 9 Core Engineering Domains with In-Browser PPT Presenters, IEEE Synopsis Generators, and AI Viva Defense Bots.

---

## 🌟 Key Features

- **450 Verified Projects**: Curated across 9 domains (AI & Machine Learning, IoT & Embedded Systems, Java Enterprise, Mobile Flutter, Blockchain Web3, Web & Full Stack, Python Data Science, Cybersecurity, and C/C++ Systems).
- **In-Browser PPT Presentation Viewer**: 10-slide decks for each project with slide navigation, presenter notes, and fullscreen mode.
- **Interactive AI Viva-Voce Defense Bot**: Practice tough examiner defense questions with live feedback, technical scoring, and readiness evaluation.
- **1-Click Customized ZIP Kit**: Client-side bundling of complete source code, IEEE-formatted synopses, system specifications, and defense cheat sheets.
- **AI Customizer Studio**: Personalize presentations and documentation with student names, university credentials, and supervisor details.
- **Fast 10-Item Progressive Pagination**: Smooth step-by-step browsing with instant category, degree, and academic year filtering.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla CSS3 (Glassmorphism & Neon Glow Tokens), JavaScript (ES6+)
- **Icons & Libraries**: Lucide Icons, JSZip, FileSaver.js, Canvas Confetti
- **Backend & Database**: Python 3 HTTP Server, MongoDB (Optional Cloud/Local Persistence)

---

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/adityanegi-hu/project.in.git
   cd project.in
   ```
2. Start the local development server:
   ```bash
   python server.py
   ```
3. Open `http://127.0.0.1:3000` in your browser.
