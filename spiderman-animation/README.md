# The Amazing Spider-Man Front-End Experience 🕷️🕸️

An interactive, high-performance HTML5 Canvas, Web Audio API, and physics-based Spider-Man animation built for modern browsers.

## 🚀 Features

- **60 FPS Physics Simulation:**
  - Real-time pendulum swing physics with tension and gravity calculations.
  - Fluid character transitions, mid-air acrobatic flips, and responsive orientation.
  - Procedural Manhattan night skyline with multi-layer parallax scrolling, glowing skyscraper windows, and atmospheric moon.
- **3 Interactive Experience Modes:**
  1. **City Patrol:** Cinematic auto-swinging across NYC skyscrapers with dynamic building anchor detection and mid-air tricks.
  2. **Web Sandbox:** Click or tap anywhere to shoot custom web anchor lines, slingshot Spidey with mouse fling physics.
  3. **Inverted Hang:** Iconic upside-down Spidey dangling on a web thread from above, reacting to mouse proximity with pendulum physics and expressive eyes.
- **4 Iconic Suits:**
  - **Classic:** Iconic red & blue suit with McFarlane-style webbing and chest emblem.
  - **Miles Morales:** Sleek stealth black & crimson suit with bio-electric venom spark effects.
  - **Symbiote:** Obsidian alien suit with sharp white logo and aggressive lenses.
  - **Iron Spider:** Metallic crimson & armor gold with 4 robotic mechanical waldoes (spider arms).
- **Comic Book Action Engine:**
  - Expressive mask lenses with reactive blinking and squinting.
  - Steve Ditko-style "Spider-Sense" warning lightning bolts and audio alerts.
  - Floating comic action popups ("THWIP!", "SWOOSH!", "FLIP!").
- **Zero-Dependency Web Audio Synthesizer:**
  - Synthesizes realistic "THWIP!" web shooter sounds, swing wind whooshes, and spider-sense chimes directly in code using Web Audio API without requiring any external audio files.

## 🎮 Controls

| Action | Control |
|---|---|
| **Shoot Web** | Click / Tap anywhere on screen |
| **Sling / Fling** | Click & drag Spider-Man |
| **Spider-Sense** | Click "Spider-Sense" button or hover near his head |
| **Acrobatic Flip** | Press `Spacebar` or click "Aerial Flip" |
| **Toggle Audio** | Click the 🔊 sound button |
